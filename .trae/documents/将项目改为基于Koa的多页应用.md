# 将项目改为基于Koa的多页应用

## 项目结构调整
1. **合并项目目录**：将前端和后端代码合并到一个目录中
2. **创建public目录**：用于存放静态文件，包括构建后的Vue应用
3. **调整配置文件**：更新package.json，包含所有必要的依赖

## 后端修改
1. **修改Koa服务器**：
   - 添加静态文件服务中间件
   - 保留现有的API路由
   - 配置首页路由，指向index.html

2. **数据库连接**：
   - 保留现有的MySQL数据库连接
   - 确保schema.sql文件可用于初始化数据库

## 前端修改
1. **构建Vue应用**：
   - 执行 `npm run build` 生成静态文件
   - 将构建产物复制到public目录

2. **API调用调整**：
   - 修改前端的API调用地址，使用相对路径
   - 确保前端能够正确与后端API通信

## 部署配置
1. **启动脚本**：
   - 更新package.json中的启动脚本，使用Koa服务器启动整个应用

2. **环境配置**：
   - 确保数据库连接配置正确
   - 配置端口和其他服务器设置

## 测试验证
1. **功能测试**：
   - 测试用户登录和注册功能
   - 测试图片上传和分类功能
   - 测试API响应和数据库操作

2. **性能测试**：
   - 验证静态文件加载速度
   - 测试API响应时间

通过以上步骤，我们将把现有的前后端分离项目改为一个基于Koa的多页应用，保持所有功能不变的同时，简化部署和维护流程。
